# React Native App

Приложение написано на React Native (CLI, без Expo) и показывает список доступных смен для подработки, полученных по геолокации пользователя.

# Основной функционал

- Запрос точной геолокации пользователя при первом запуске.
- Получение списка смен по координатам.
- Отображение списка смен с краткой информацией (компания, адрес, дата, оплата и т.д.).
- Экран с подробными данными выбранной смены (используются уже загруженные данные).
- Управление состоянием через **Redux Toolkit**.
- Обработка загрузки, ошибок и обновления данных.

# Технологии

- React Native CLI
- TypeScript
- Redux Toolkit
- Axios
- React Navigation
- react-native-geolocation-service

# Как запустить проект

npm install
npm run android
