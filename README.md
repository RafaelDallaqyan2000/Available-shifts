# Shift Work App - Приложение для поиска подработок

React Native приложение для отображения списка доступных смен для подработки по геолокации пользователя.

## Описание задания

Создать небольшое приложение на React Native (CLI, без Expo), которое показывает список доступных смен для подработки, полученных по геолокации пользователя.

### Функциональные требования

1. ✅ При первом запуске запросить точную геолокацию пользователя
2. ✅ Получить список смен в городе, передав координаты пользователя в запрос API
3. ✅ Отобразить список смен с краткой информацией
4. ✅ По нажатию на элемент списка открыть экран с подробными данными выбранной смены
5. ✅ Данные для экрана деталей брать из ранее полученного списка (без повторного запроса)

### Технологический стек

- **React Native CLI** (версия 0.82.0)
- **TypeScript** для типобезопасности
- **MobX** для управления состоянием
- **React Navigation** для навигации между экранами
- **react-native-geolocation-service** для работы с геолокацией

## Описание данных

Поля возвращаемого объекта смены:

- **logo** – ссылка на логотип нанимателя
- **address** – адрес проведения смены
- **companyName** – имя компании нанимателя
- **dateStartByCity** – дата начала смены
- **timeStartByCity** – время начала
- **timeEndByCity** – время окончания
- **currentWorkers** – сколько людей уже набрано
- **planWorkers** – сколько людей требуется
- **workTypes** – наименование типа услуги
- **priceWorker** – сумма выплаты за смену (в рублях)
- **customerFeedbacksCount** – количество отзывов о клиенте
- **customerRating** – рейтинг нанимателя (максимум 5)

## Установка и запуск

### Требования

- Node.js >= 20
- React Native CLI
- Android Studio (для Android)
- Xcode (для iOS, только macOS)

### Установка зависимостей

```bash
npm install
```

### Для iOS

```bash
# Установить CocoaPods зависимости
cd ios
bundle install
bundle exec pod install
cd ..
```

### Запуск приложения

```bash
# Запустить Metro bundler
npm start

# Запустить на Android
npm run android

# Запустить на iOS
npm run ios
```

## Особенности реализации

### Управление состоянием (MobX)

Используется `ShiftStore` для управления:

- Списком смен
- Выбранной сменой
- Состоянием загрузки
- Ошибками
- Геолокацией пользователя

### Оптимизация производительности

- Использование `FlatList` для эффективного рендеринга больших списков
- Мемоизация компонентов с помощью `observer` из MobX
- Lazy loading данных
- Pull-to-refresh для обновления данных

### UI/UX

- Современный дизайн в стиле iOS
- Визуальная обратная связь (индикаторы загрузки, состояния ошибок)
- Адаптивная верстка
- Отображение статуса набора работников (цветовая индикация полной занятости)
- Рейтинговая система с отзывами

## API

Используется API: `https://mobile.handswork.pro/api/shift`

Параметры запроса:

- `latitude` - широта
- `longitude` - долгота

Пример: `https://mobile.handswork.pro/api/shift?latitude=55.751244&longitude=38.987221`
